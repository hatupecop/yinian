Bits 多图展示 · 布局对比

挑一种你喜欢的，告诉我编号，我就把它落到余年的 Bits 详情页。下面都是纯 CSS 占位图，离线也能看。

A · 并排 2 列方格推荐

最紧凑，一屏能看 4–6 张；方形象素，和选择器缩略图一致。

B · 横滑单行

像朋友圈九宫格那样左右滑；单列大图，点击感强。

C · 大图竖排

每张都大、4:3，从上往下读，最沉浸；图多时较长。

D · 瀑布流

高度不一、错落排布，最有"相册"感；图多也透气。

选择器外观（添加 / 删除）

空状态中心是 + ；加图后并排，每张右上角小 × 可删。
